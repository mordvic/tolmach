Pre-flight scan found two defects in the plan and fixed them before dispatch:
  - cancel() would not have cancelled: the plan stored a wrapper Task around the
    translating Task, and Task {} does not inherit cancellation from its creator.
    Now the translating task itself is held.
  - token order could scramble: a Task { @MainActor in } per piece is scheduled
    independently. Replaced with an AsyncStream consumed on the main actor, which
    preserves the serial order onToken already delivers.
