Ниже приведён фрагмент кода, который нельзя изменять ни на один символ.
Функция внутри блока называется `calculateTotal`, и её имя менять нельзя.
Мы случайно допустили опечятку в этом предложении, хотя её легко заметить.
В росписании работ мы указали неправильную дату, и это нужно исправить.

```
function calculateTotal(items) {
    return items.reduce((sum, item) => sum + item.price, 0);
}
```
