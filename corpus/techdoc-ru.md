## Синхронизация сессии

Сервер профилей считается источником истины для состояния сессии. Клиент не должен самостоятельно продлевать срок жизни токена — он обязан дождаться ответа от `/session/sync` и применить полученное состояние целиком. Заголовок `Authorization` обновляется только после успешного ответа сервера.

```typescript
const state = await syncSession({ signal: controller.signal });
if (state.status === "revoked") {
  await hardLogout({ reason: "server-revoked" });
}
```

Если запрос завершился таймаутом, повторите его с экспоненциальной задержкой, но не более трёх раз. Полную спецификацию протокола см. на странице https://example.org/docs/session-sync, раздел «Session Sync».

> **Важно:** повторные попытки не должны блокировать основной поток интерфейса.

Подробности — в журнале изменений релиза 19072.
